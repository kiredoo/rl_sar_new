Resources Consumed by Callbacks/Modules

  • We measure resource consumption on a callback basis. We first focus on the CPU utility.
  • CPU utility = execution_time_in_seconds / (1 / HZ) = execution_time_in_milliseconds * HZ / 1000.
  • The execution time (ET) is measured in NVidia Jetson Orin. The worst case execution time (WCET) is estimated by the extreme value theory. Please note that WCET is not always fitted well.
  • ET is measured by uprobe/kprobe. Probes cannot distinguish CPU computation from GPU computation. If a callback involves GPU computation, then its CPU utility estimation is unreliable.
